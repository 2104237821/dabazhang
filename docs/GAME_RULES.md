# 打八张完整规则 v1.0

## 1. 用牌、座位与阵营

- 使用一副 54 张扑克牌，包含大王和小王。
- 四名玩家固定坐在四个座位，行动方向为逆时针。
- 相对座位是队友：0/2 为一队，1/3 为一队。
- 普通牌点数从大到小为：A、K、Q、J、10、9、8、7、6、5、4、3、2。
- 大小王只用于防守；二者都能压住任何攻击牌，不需要比较两张王之间的大小。

## 2. 主花色与发牌

1. 洗匀整副牌，随机翻出一张非王牌；若翻到王则重新抽取。
2. 翻出牌的花色成为本局固定主花色，其他花色为普通花色。
3. 把翻出的牌放到牌堆最下面，并始终公开其牌面，直到它被摸走或被主2换底。
4. 从随机确定的起始座位开始，四人逆时针每次摸一张，共摸八轮，每人得到八张，牌堆剩余 22 张。
5. 整场第一局的首攻玩家随机确定；同一房间再来一局时，由上一局最先正式出完的玩家首攻。

## 3. 进攻

- 每轮由一名主攻玩家先出一张牌，逆时针下一名仍在场的玩家是防守方。
- 大小王不能作为首攻牌、追加进攻牌或协攻牌。
- 一次追加一张牌。追加牌的点数必须与本轮桌面任意已经出现的普通牌点数相同，花色不限。
- 不设置额外的最大进攻张数；主攻方可以继续追加或主动结束进攻。
- 防守方用最后一张手牌成功防住后，所有追加和待审批协攻立即终止，进入本轮结算。

## 4. 防守

- 面对普通非主攻击牌，如果防守方手中存在同花色且点数更大的牌，只能使用这些牌或大小王防守。
- 如果不存在同花色更大牌，可以使用任意主花色牌或大小王防守。
- 面对主花色攻击牌，只能使用点数更大的主花色牌或大小王防守。
- 不同普通花色之间不能互相压制。
- 防守方即使有合法防守牌，也可以主动选择收牌以保留大牌。
- 主动收牌或无法防守时，防守方收走本轮桌面的全部攻防牌。

## 5. 队友协攻

- 主攻方正在攻击敌方时，仍在场的队友可以请求协攻。
- 协攻牌必须符合追加点数规则，且不能是大小王。
- 一次只能存在一个待审批请求；牌在批准前仍留在协攻者手中。
- 主攻方看到具体申请牌并决定允许或拒绝。只有批准后该牌才进入桌面并要求防守。
- 主攻方攻击自己的队友时，其他任何玩家都不能协攻。
- 当只剩三名玩家时仍使用上述队伍关系：攻击敌人时队友可以协攻，攻击队友时第三名敌人不能协攻。

## 6. 主2换底牌

- “主2”仅指固定主花色的 2；换底牌不会改变主花色。
- 只有当前持有主2的玩家可以发动；整局最多成功发动一次。
- 可发动时机：自己的摸牌过程、自己的进攻阶段、自己的防守阶段，以及防守失败收牌后到补牌前的结算窗口。
- 发动时从手牌移除主2，拿取牌堆最下面的牌加入手牌，再把主2放到牌堆最下面；牌堆数量不变，换牌本身不算出牌。
- 防守方可先换底，再立即使用换到的更大主牌防守。
- 玩家可以选择不换，把主2当普通主牌使用。
- 初始翻牌本身就是主2时，本局禁用换底。
- 主2正常打出并在防守失败时被收走，新持有者可以在收牌后的窗口发动。
- 主2进入弃牌区、牌堆已空、底牌已经正常摸走或本局已经换过时，换底能力永久失效。
- 换底后的主2以后被摸到时只是一张普通主牌，不能再次换底。

## 7. 本轮结算与下一轮

- 防守成功：桌面全部牌进入弃牌区，原防守方成为下一轮主攻；若其正式出完，则按逆时针跳过已出完玩家。
- 防守失败或主动收牌：失败者不能成为下一轮主攻；从失败者的下家开始找到下一名未出完玩家作为主攻。
- 新防守方始终是新主攻方逆时针方向的下一名未出完玩家。
- 玩家正式出完后退出进攻、防守和协攻，但座位和队伍关系保持不变。

## 8. 补牌

- 每轮结算后，从该轮原主攻玩家开始，按逆时针逐人补牌。
- 每名玩家一次补到八张；已有八张或更多时不摸牌，也不弃牌。
- 若轮到某玩家时剩余牌不足以补到八张，该玩家拿走全部剩余牌，牌堆立即变空，后续玩家不再补牌。
- 牌堆为空后，后续各轮不再补牌。
- 手牌打空但牌堆仍有牌时仍需补牌，不能算正式出完。

## 9. 出完与胜负

- 必须同时满足“牌堆为空、手牌为空、本轮结算完成”才算正式出完。
- 正式出完顺序按玩家手牌实际变为零的动作顺序记录。
- 一支队伍的两名玩家都正式出完时，该队立即获胜，本局结束。
- 若同一轮两队都可能满足条件，以各队第二名队员更早完成出完的一队获胜。
